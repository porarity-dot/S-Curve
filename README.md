> **ระบบบริหารแผนงานโครงการ ติดตามความคืบหน้าสะสม (S-Curve) และแผนภูมิแกนต์ (Gantt Chart)**

## 🌟 ฟังก์ชันเด่น (Key Features)

### 1. 📈 กราฟความคืบหน้าสะสม (S-Curve & Performance Analysis)
- **Planned S-Curve (เส้นสีน้ำเงิน)**: เส้นแสดงแผนงานสะสมตามน้ำหนักเวลาตลอดอายุโครงการ (0% - 100%)
- **Actual S-Curve (เส้นสีเขียว)**: เส้นแสดงความคืบหน้าของผลงานที่ทำได้จริงสะสมจนถึงวันตัดรอบประเมินผล (Status Date)
- **Forecast Curve (เส้นประสีส้ม)**: คาดการณ์แนวโน้มระยะเวลาแล้วเสร็จจริง 100% โดยคำนวณจากอัตราความเร็ว (Velocity / Burn Rate) จริงที่ผ่านมา
- **Status Date Cutoff (เส้นประสีแดง)**: ระบุวันประเมินผลพร้อมปรับเปลี่ยนวันที่เพื่อดูสถานะย้อนหลังหรือล่วงหน้าได้
- **Interactive Tooltip & Download PNG**: ชี้เมาส์ดูข้อมูลรายละเอียดรายวัน และกดส่งออกภาพกราฟความละเอียดสูงเพื่อนำไปใส่ในสไลด์นำเสนอได้ทันที

### 2. 📅 แผนภูมิแกนต์แบบอินเทอร์แอคทีฟ (Interactive Gantt Chart)
- แสดงแถบเวลาตามจริงเทียบกับแผนงานแบบรายวันและรายสัปดาห์
- จัดกลุ่มตามหมวดหมู่งานอัตโนมัติ
- แถบความคืบหน้าจริง (Progress Fill) ซ้อนอยู่ในแถบแผนงาน
- ปุ่มลัด **"ไปที่วันประเมิน"** เพื่อเลื่อนตารางไปยังตำแหน่งปัจจุบันทันที

### 3. 📋 ระบบจัดการรายการงาน (Task Management)
- **เพิ่ม / แก้ไข / ลบงาน**: รองรับทั้งการลบทีละงาน, ลบแบบกลุ่มด้วย Checkbox, และปุ่มล้างงานทั้งหมดเพื่อเริ่มโปรเจกต์ใหม่
- **Instant Slider**: ปรับความคืบหน้าจริง (%) ด้วยแถบสไลเดอร์ ตัวเลขและป้ายสถานะ (`ยังไม่เริ่ม` ➔ `กำลังดำเนินงาน` ➔ `เสร็จสมบูรณ์` / `ล่าช้ากว่าแผน`) จะเปลี่ยนสีและข้อความทันทีโดยไม่มีอาการค้าง
- **Auto-Weight Calculation**: คำนวณค่าน้ำหนักงานแต่ละรายการอัตโนมัติตามสัดส่วนจำนวนวันทำงาน (Duration)
- **ระบบค้นหาและตัวกรอง**: ค้นหาตามชื่องาน, ผู้รับผิดชอบ, หมวดหมู่งาน และสถานะงาน

### 4. 👷 บันทึกสถิติกำลังคนหน้างาน (Daily Site Log & Manpower)
- บันทึกจำนวนคนงานเข้าปฏิบัติงานประจำวัน
- บันทึกสภาพอากาศ ปัญหา และอุปสรรคหน้างาน
- สรุปตัวเลขยอดรวม Man-days, ค่าเฉลี่ยคนงานต่อวัน, และสถิติคนงานสูงสุด พร้อมกราฟแท่งความหนาแน่น

### 5. 📊 ตัวชี้วัดมาตรฐานสากล (EVM & Earned Schedule)
- **Schedule Variance (SV %)**: ผลต่างความคืบหน้าจริงเทียบกับแผนงาน ณ วันประเมินผล
- **Schedule Performance Index (SPI)**: ดัชนีประสิทธิภาพเชิงเวลา ($SPI = \frac{Actual\%}{Planned\%}$)
- **Earned Schedule (ES)**: ประเมินว่าผลงานที่ทำได้จริง เทียบเท่ากับแผนงาน ณ วันที่เท่าไร (เร็วกว่าแผนกี่วัน หรือ ล่าช้ากว่าแผนกี่วัน)

### 6. 💾 การจัดเก็บและสำรองข้อมูล (Data Persistence & Export)
- **Local Storage Auto-save**: ข้อมูลจะถูกบันทึกในเบราว์เซอร์อัตโนมัติ รีเฟรชหรือปิดแท็บข้อมูลไม่สูญหาย
- **Export / Import JSON**: สำรองไฟล์ข้อมูลโครงการทั้งหมดเพื่อนำไปเปิดในเครื่องอื่น
- **Export to CSV**: ดาวน์โหลดข้อมูลตารางงานไปเปิดใน Microsoft Excel
- **Light / Dark Mode**: สลับธีมสีขาวและธีมมืดเพื่อความสบายตา

## 🚀 วิธีการใช้งาน (Getting Started)

### วิธีที่ 1: เปิดใช้งานบนเครื่องคอมพิวเตอร์ของคุณโดยตรง
1. ดาวน์โหลดหรือคัดลอกไฟล์ `index.html`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่าน Google Chrome, Microsoft Edge, Safari หรือ Firefox ได้ทันที โดยไม่ต้องติดตั้งซอฟต์แวร์เพิ่มเติม

### วิธีที่ 2: ใช้งานออนไลน์ผ่าน GitHub Pages (แนะนำ)
คุณสามารถนำไฟล์นี้ไปเปิดบริการผ่าน GitHub Pages เพื่อให้มีลิงก์เว็บไซต์ออนไลน์ (URL) ใช้งานร่วมกับทีมงานได้ฟรี 100%:
1. อัปโหลดไฟล์ขึ้น GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. เลือก Branch: `main` และโฟลเดอร์: `/(root)` แล้วกด **Save**
4. คุณจะได้ลิงก์ เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อโปรเจกต์>/` เพื่อเปิดใช้งานได้จากทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
